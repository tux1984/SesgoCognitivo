# Bloque 3 — Recomendador con diversidad (DART)

Selector con restricción de diversidad sobre las columnas anotadas (`direccion`, `actor_objetivo`,
`intensidad`) del corpus, usando las métricas de Vrijenhoek et al. (Representación, Activación,
Voces alternativas, Fragmentación). Pendiente de construcción — ver OE3/T3.1-T3.3 en
`docs/propuesta/` y la sección 6 de `docs/metodologia/`.
